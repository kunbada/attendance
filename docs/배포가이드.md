# 배포 가이드 (Cloudflare 버전)

> 구조: 화면(`web/`)은 **GitHub Pages**, 서버(`worker/`)와 데이터는 **Cloudflare**(무료)에서 돌아갑니다.
> 서버 코드를 올리는 명령은 Claude가 대신 실행합니다. 사용자는 **가입·로그인·토큰 입력**만 하면 됩니다.

---

## 1. Cloudflare 가입 (사용자, 약 5분)
1. <https://dash.cloudflare.com/sign-up> 에서 이메일과 비밀번호로 가입합니다. (카드 등록은 필요 없습니다.)
2. 이메일로 온 인증 링크를 눌러 인증합니다.
3. **2단계 인증을 켭니다.** 오른쪽 위 프로필 → **My Profile → Authentication → Two-factor authentication**.
4. 가입이 끝나면 Claude에게 알려 주세요.

## 2. 서버 올리기 (Claude가 실행, 사용자는 클릭 1번)
Claude가 아래를 순서대로 실행합니다. 중간에 **브라우저 창이 열리면 [Allow](허용)** 만 눌러 주세요.

1. `npx wrangler@4 login` → 브라우저에서 **Allow** (Claude가 Cloudflare에 배포할 수 있게 허용)
2. D1 데이터베이스 만들기 → `wrangler.toml` 에 DB 번호 기록
3. 표(테이블) 생성: `schema.sql` 적용
4. 비밀 값 등록 (서버에서 비밀번호 해시·급여 암호화에 쓰는 값. 자동 생성)
5. 기본 설정·조직·**관리자 계정** 생성 → **초기 비밀번호가 한 번 표시됩니다. 메모하세요.**
6. 서버 배포 → `https://attendance-api.○○○.workers.dev` 주소가 나옵니다.
7. 화면의 `web/js/config.js` 에 그 주소를 넣고 GitHub에 올립니다.

> ⚠ `worker/.dev.vars` 파일에는 암호화 키가 들어 있습니다. **절대 공유·업로드하지 말고, 같은 내용을 안전한 곳(비밀번호 관리자 등)에 백업**해 두세요. 이 파일을 잃으면 저장된 급여정보와 비밀번호를 복구할 수 없습니다. (git에는 자동으로 제외됩니다.)

## 3. 텔레그램 봇 연결 (사용자, 약 5분)
1. 텔레그램 앱에서 **`@BotFather`**(파란 체크 표시) 검색 → **[시작]** → `/newbot`.
2. 봇 **이름**(예: `OO현장 호출`)과 **사용자명**(영문·숫자·밑줄, **`bot` 으로 끝나야 함**, 예: `oo_site_call_bot`)을 입력합니다.
3. 완료 메시지의 **토큰**(`123456789:AAH...` 형태)을 복사합니다.
   - ⚠ 토큰은 비밀번호와 같습니다. **채팅·메일에 붙여넣지 마세요.** 아래 4번의 터미널에만 넣습니다.
4. 이 앱의 **터미널 탭**(또는 PowerShell)에서 실행:
   ```
   cd D:\mycode\근태관리\worker
   node scripts/set-telegram.mjs
   ```
   토큰을 붙여넣고 Enter (입력이 화면에 보이지 않는 것이 정상). `웹훅 연결 완료.` 가 나오면 성공입니다.
5. 관리자 화면 **설정 > 기본 설정 > 텔레그램 봇 이름** 에 사용자명(`@` 없이)을 넣고 저장합니다.

## 4. 처음 사용 순서
1. **관리자:** `https://kunbada.github.io/attendance/admin.html` → `admin` + 초기 비밀번호 → **새 비밀번호로 변경**.
2. **설정:** 현장명, GPS 허용거리, 예약 중복 기준 저장. **조직**(본부·팀·직군)을 실제에 맞게 수정.
3. **설정 > 계정 > [+ 계정 추가]** 로 데스크 계정(역할 `데스크`)을 만들고 임시 비밀번호를 전달합니다. 첫 로그인 때 직접 바꿉니다.
4. **설정 > 가입 링크 QR** 을 직원에게 공유.
5. **직원:** 가입 → 관리자 승인 → 로그인 → 홈에서 **[텔레그램 연결]**.
6. **데스크:** `https://kunbada.github.io/attendance/desk.html` 을 열어 즐겨찾기.
7. **출근:** 관리자가 현장에서 **QR 생성 탭 → [오늘 QR 만들기]**(위치 허용) → 인쇄·게시 → 직원이 [출근하기].

## 5. GitHub Pages (화면 배포)
- 저장소 **Settings → Pages → Source: GitHub Actions** (이미 설정됨). `main` 에 올리면 `web/` 만 자동 배포됩니다.
- 주소: `https://kunbada.github.io/attendance/staff.html` (직원), `admin.html` (관리자), `desk.html` (데스크).

## 6. 운영·점검
- **서버 코드를 고쳤을 때:** Claude가 `npx wrangler@4 deploy` 를 실행해 반영합니다.
- **백업:** 데이터베이스 전체를 파일로 내려받기
  ```
  cd D:\mycode\근태관리\worker
  npx wrangler@4 d1 export attendance --remote --output=backup.sql
  ```
  (D1 은 최근 7일 안의 시점으로 되돌리는 기능도 있습니다.) `backup.sql` 에는 개인정보가 들어 있으니 안전하게 보관하세요.
- **관리자 비밀번호를 잊었거나 잠김:** 아래를 실행하면 `admin` 의 새 임시 비밀번호가 나옵니다.
  ```
  cd D:\mycode\근태관리\worker
  node scripts/make-seed.mjs
  npx wrangler@4 d1 execute DB --remote --file=.seed.sql
  ```
- **무료 한도(하루):** 서버 요청 10만 건, DB 읽기 500만 행·쓰기 10만 행. 이 앱은 하루 1만 건 안팎이라 여유가 큽니다. 한도를 넘으면 그날은 멈추고 한국 시간 오전 9시에 풀립니다.
- **직원이 PIN 5회 실패로 잠김:** 관리자 화면 [PIN 초기화].
- **서버 로그:** Cloudflare 대시보드 → Workers & Pages → `attendance-api` → Logs. 요청마다 `action 걸린시간ms` 가 남습니다.
