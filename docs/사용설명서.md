# 사용설명서

주소는 모두 `https://kunbada.github.io/attendance/` 뒤에 붙입니다.

| 누가 | 주소 | 로그인 |
| --- | --- | --- |
| 영업직원 (팀장·본부장 포함) | `staff.html` (처음 가입은 **현장별 가입 링크** `staff.html?p=현장코드#signup`) | 휴대폰 번호 + PIN 4자리 |
| 안내데스크 | `desk.html` | 아이디 + 비밀번호 (역할 `데스크`) |
| 고객 방명록 태블릿 | `guest.html` | 아이디 + 비밀번호 (역할 `방명록`), 한 번만 |
| 관리자·보조관리자 | `hub/` (통합관리, 예전 `admin.html` 은 자동 이동) | 아이디 + 비밀번호 (역할 `관리자`, `보조관리자`) |

---

## 1. 영업직원

**가입** — 관리자에게 받은 **우리 현장의 가입 링크(QR)** 로 접속 (링크마다 현장이 정해져 있어, 가입하면 그 현장 소속이 됩니다. 한 사람은 한 번에 한 현장에만 소속됩니다) → 성명·예명·휴대폰·직군(영업이면 본부·팀)·주민번호·계좌·PIN 4자리 입력 → 개인정보 동의 → 신청. 관리자(또는 담당 팀장·본부장)가 승인하면 로그인할 수 있습니다.

**내 휴대폰 확인** — 본인 휴대폰에서만 로그인됩니다. 휴대폰을 바꿨다면 새 폰에서 **[기기 변경 요청]**을 누르고 승인을 기다리세요. 다른 사람이 내 번호와 PIN을 알아도 다른 폰에서는 로그인할 수 없습니다.

**출근** — 현장에 붙은 QR을 **[출근하기]**로 촬영합니다 (카메라·위치 허용). 현장 반경 안이어야 하고, 하루 한 번만 됩니다. 한 휴대폰으로 다른 사람이 출근할 수는 없습니다.

**고객 방문 예약** — **[고객 방문 예약]**에서 고객 전화번호 **뒤 5자리**, 방문 예정일, (성별), 메모를 등록합니다. 같은 고객이 이미 예약되어 있으면 "이미 예약된 고객입니다."로 막힙니다. 예정 건은 날짜·메모 수정과 취소가 됩니다.

**내 지급내역** — 홈의 **[내 지급내역]**: 정산이 **확정된** 내역만 보입니다 (현장·기간·근무일수·지급액·공제 3.3%·실지급액, 날짜별 내역). 다른 현장으로 옮겼어도 이전 현장에서 받을 내역이 함께 보입니다.

**호출 알림 받기 (텔레그램)** — 홈의 **[텔레그램 연결]** → 텔레그램이 열리면 **[시작]**. 연결 후 데스크가 부르면 텔레그램에 `[호출] ... 고객 도착` 메시지와 **[확인]** 버튼이 옵니다. **[확인]**을 꼭 눌러 주세요 (3분 안에 누르지 않으면 데스크에 빨간색으로 표시됩니다).

## 2. 팀장·본부장

직원 기능을 그대로 쓰고, 관리자가 **승인 권한**을 준 경우에만 홈에 **[직원 승인 관리]**가 보입니다.
- **팀장:** 우리 팀 직원의 가입 승인·반려, 퇴사 처리
- **본부장:** 우리 본부 직원·팀장의 가입 승인·반려, 퇴사 처리
- 우리 팀·본부 직원이 호출되면 `[호출 알림]` 메시지가 옵니다 (텔레그램 연결 필요, 확인 버튼 없음).

## 3. 안내데스크 (`desk.html`)

메뉴 순서: **예약검색 · 방명록 · 직원검색 · 예약명단**

1. **예약검색** — 큰 숫자판에 고객 전화번호 **뒤 5자리**를 누르면 오늘 예약이 나옵니다 (필요하면 성별 버튼). **[담당 ○○ 호출]**을 누르면 담당 직원에게 호출이 가고 담당 팀장·본부장에게는 알림이 갑니다. 이 화면 맨 아래 **오늘 호출** 목록에 호출·담당 없음 기록이 쌓이고 [재호출]도 여기서 합니다 (다른 탭에는 나오지 않습니다. 오늘 방문객 수는 방명록 통계가 기준입니다).
   - 예약이 없고 고객이 직원 이름을 말하면 **[직원 찾기]**, 둘 다 없으면 **[담당 없음으로 기록]**.
2. **방명록** — 고객이 태블릿에 입력한 내용이 **확인 필요**로 뜹니다. 같은 전화번호 뒤 5자리의 **예약이 있으면 `예약 있음`**, 이전 방문 기록이 있으면 **`방문이력 N회`**(물음표가 붙으면 뒤 5자리만 같은 경우라 다른 고객일 수 있음)가 이름 옆에 표시되고, **담당 본부/팀/담당자가 자동으로 채워집니다**(`자동 입력(예약)` 또는 `(방문이력)` 표시). 다르면 [수정]에서 바꾸세요. 예약 담당자를 그대로 호출하면 그 예약은 방문 처리됩니다. **[수정]**에서 **성별**을 입력하고 **본부 → 팀 → 담당자**를 고릅니다 (등록된 담당자가 없으면 "없음", 본부를 고르지 않으면 워킹). 저장 후 줄 맨 앞 **[호출]**. 직접 입력은 **[+ 방명록 입력]**.
3. **직원검색** — 직원 이름·예명·전화번호 일부·본부/팀을 입력하고 **[검색]**(또는 Enter)을 누르면 목록이 나옵니다. **검색어가 없으면 아무도 나오지 않습니다.** 오른쪽 **예약고객 5자리**는 입력하지 않아도 되고, 입력 후 **[조회]**를 누르면 그 예약이 어느 직원 것인지 바로 보여 줍니다.
4. **예약명단** — 날짜별 예약 목록 (예약번호=고객 뒤 5자리, 본부·팀·직원·직원 전화번호). 검색이 되고 오늘 예정 건은 바로 호출할 수 있습니다.

**맨 아래 오늘 방문 목록** — 15초마다 갱신. `호출함`(노랑) → 직원이 [확인]하면 `확인함`(초록). 3분 넘게 확인이 없으면 `미확인`(빨강) → **[재호출]**. 텔레그램이 연결되지 않은 직원은 호출 대신 **전화번호가 크게** 표시되니 전화로 연락하세요.

## 4. 고객 방명록 태블릿 (`guest.html`)

고객이 성명, 전화번호, 혼자/함께 방문(인원), 개인정보 동의를 입력하고 **[제출]**합니다. 완료 화면에서 **[처음 화면으로 돌아가기]**를 누르면 바로 다음 고객이 쓸 수 있고, 누르지 않아도 7초 뒤 돌아갑니다. 입력 중 90초 동안 아무도 만지지 않으면 내용이 지워집니다.
- 태블릿 로그인을 해제하려면 화면 맨 위 **제목을 3초 길게** 누르세요.

## 5. 통합관리 (`hub/`) — 관리자·보조관리자

로그인하면 화면 위쪽 **현장** 선택에서 보고 싶은 현장을 고릅니다. 이후 모든 메뉴는 **선택한 현장** 기준입니다. 관리자는 모든 현장, **보조관리자는 관리자가 지정한 현장만** 보입니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 홈 | 오늘 출근·예약·호출·담당 없음·방명록, 최근 14일 추이 그래프, 본부·팀·직군별 출근율, 월별 직원 TOP 10과 예약 대비 방문율 |
| 프로젝트 | 현장 목록(인원 수·가입 코드·출근 허용거리·예약 중복 기준), **관리자만**: [+ 새 프로젝트]·[수정]. 현장을 만들거나 수정할 때 **현장 설정(출근 허용거리, 예약 중복 기준)** 도 함께 입력합니다. 현장을 만들면 기본 직군이 함께 생깁니다 |
| 인사관리 > 현장인력관리 | **직원**(현장·직급 열 포함) / **전체 현장 검색**(이름·전화번호 일부로 모든 현장에서 찾기. 보조관리자는 담당 현장 안에서만. 관리자는 여기서 바로 [현장 이동]) / **조직**: 직군·본부·팀 / **가입 링크**: 이 현장 전용 QR·주소. 직원 탭: 가입 승인·반려, 수정, **직급(팀장·본부장)과 승인 권한 지정**, PIN 초기화, 기기 변경 승인, 퇴사, 급여정보(마스킹, [원문 보기]는 기록됨 — 관리자 또는 관리자가 허용한 보조관리자만), **[현장 이동]**(관리자만, 이동 전에 이번 달 출근일수와 취소될 예약 수를 보여 줍니다) |
| 인사관리 > 현장근태관리 | 현장에서 **[오늘 QR 만들기]** (위치 허용) → 인쇄. 다시 만들면 이전 QR은 무효. 날짜별 출근자·미출근자·실패 기록, 월별 출근일수 표(원본 출근일수 + **인정 근무일수**), CSV. **[보정]**: 날짜를 골라 **인정**(출근 기록이 없어도 1일) / **불인정**(기록이 있어도 0일) / **반일**(0.5일)로 덮어쓰고 사유를 남깁니다 (원본 기록은 그대로) |
| 고객관리 > 방문고객 | 예약·호출 현황(기간·본부·팀·직원 필터, CSV) / 방명록(방문 팀수·방문객수, 분양·워킹·확인 필요, 일별 그래프, **CSV·통계 CSV 내보내기** — 내보내기는 기록됨). 설문고객·TM고객·상담고객·데이터통합관리는 이후 단계에서 추가됩니다 |
| 용역관리 > 지급 설정 | **직군별 기본 지급**(상담사·홍보단·도우미·영업 등 직군마다 기본 일당·주기·3.3% 공제 등)을 먼저 정하고, 다르게 줄 직원만 **개인별 지급 설정**을 합니다. 개인 설정이 있으면 개인이 우선, 없으면 직군 기본이 적용됩니다 ([직군 기준으로]로 개인 설정을 지우고 되돌릴 수 있음). 항목: 일당·지급 주기(주/월)·일당 지급 대상·판매수수료 대상(영업 직군이 기본)·3.3% 공제 여부·적용 시작일. 바꾸면 이력이 쌓이고 정산은 날짜별로 그날 적용된 일당으로 계산합니다 |
| 용역관리 > 일급 정산 | **[+ 새 정산]** → 주기·기간 선택 → 기간 안에 일한 사람의 명세가 만들어집니다(인정 근무일수 × 일당, 소득세 3%·지방소득세 0.3% 각각 원 단위 절사). 대상에서 빠진 사람은 이유가 표시됩니다 (설정 없음, 주기 다름 등). 개인별 [명세](날짜별 내역·인쇄), [조정](±금액, 사유 필수) → **검토 요청 → 확정 → 지급완료 처리**. 확정은 관리자(또는 확정 권한을 받은 보조관리자)만 하고, 확정된 회차는 수정할 수 없습니다(정정은 다음 회차의 조정으로). **이체 파일(CSV)**은 관리자(또는 급여 원문 보기가 허용된 보조관리자)만 만들 수 있고 만든 기록이 남습니다. 근태를 보정했거나 설정을 바꿨다면 [다시 계산]을 누르세요 |
| 설정 (관리자만) | **공통 설정**(모든 현장에 함께 적용: 텔레그램 봇 이름 등. 앞으로 추가되는 설정도 공통 값 위주) / **계정**: 관리자·보조관리자·데스크·방명록 계정과 담당 현장, 보조관리자의 급여 원문 보기·지급 확정 허용 |

(계약관리·출납관리 메뉴는 해당 기능이 만들어질 때 추가됩니다.)

**보조관리자 만들기:** 설정 > 계정 > [+ 계정 추가] → 역할 `보조관리자`, **담당 현장 체크**, 임시 비밀번호 → 상대방에게 전달. 급여정보 원문 보기를 허용하려면 계정에서 해당 체크박스를 켭니다 (기본은 불가).
**데스크·방명록 계정:** 담당 현장을 **1개** 골라야 하고, 그 현장의 화면으로만 들어갑니다.

**매일 아침 순서:** ① 현장 선택 → ② 인사관리 > 현장근태관리에서 QR 생성 → ③ 현장인력관리에서 승인 대기 직원 확인 → ④ 홈에서 출근 현황 확인.
**월 정산 순서:** ① 현장근태관리에서 한 달 근태 확인·보정 → ② 지급 설정 확인 → ③ 용역관리 > 일급 정산에서 새 정산 → ④ 명세·조정 확인 → 검토 요청 → 확정 → 이체 파일 → 지급완료.

## 6. 자주 묻는 질문

- **"○○ 현장에 가입되어 있습니다"** — 그 번호가 다른 현장에 이미 있습니다. 그 현장으로 로그인하거나 관리자에게 현장 이동을 요청하세요.
- **"이 휴대폰은 이미 010-****-1234 번호로 …"** — 휴대폰 한 대에는 한 명만 가입됩니다. 같은 분이면 그 번호로 로그인하고, 시험 가입이면 관리자가 그 직원을 반려·퇴사 처리하면 휴대폰이 풀립니다.
- **"등록된 휴대폰이 아닙니다"** — 다른 폰으로 로그인했습니다. 폰을 바꿨다면 [기기 변경 요청] 후 관리자 승인.
- **PIN을 5번 틀려 잠김** — 통합관리 인력 > 직원 [PIN 초기화].
- **"현장에서 ○○m 떨어져 있습니다"** — 현장 안에서 위치(GPS)를 켜고 다시 시도. 실내에서 오차가 크면 창가·실외에서 시도하거나 관리자가 허용거리를 늘립니다.
- **"오늘 QR이 아닙니다"** — 어제 QR을 찍었거나 QR이 다시 만들어졌습니다. 오늘 붙은 QR을 찍으세요.
- **호출 메시지가 안 옵니다** — 텔레그램 연결 상태 확인(홈 화면). 안 되어 있으면 [텔레그램 연결]을 다시.
- **관리자 비밀번호 분실** — 로그인 화면의 **[비밀번호를 잊으셨나요?]** → 아이디 입력 → 등록된 이메일로 온 6자리 코드와 새 비밀번호 입력. (이메일 미설정 시 `docs/배포가이드.md` 6장 참고)
