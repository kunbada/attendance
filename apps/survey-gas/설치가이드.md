# 사전판촉 설문조사 앱 — 설치 가이드

구글 시트 + Apps Script로 동작합니다. 서버 비용 없이 구글 계정 하나로 운영합니다.

## 1. 설치 (10분)

1. 구글 드라이브에서 **새 스프레드시트** 생성 → 이름: `사전판촉 설문 DB`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 지우고 → 받은 **Code.gs** 전체 붙여넣기
4. 왼쪽 `+` → **HTML** → 이름 `Admin` (확장자 없이) → **Admin.html** 붙여넣기
5. 같은 방법으로 `Survey` 파일 생성 → **Survey.html** 붙여넣기
6. 상단 함수 선택에서 **setup** 선택 → **실행** → 권한 승인
   - "확인되지 않은 앱" 경고가 나오면: 고급 → (안전하지 않음)으로 이동 → 허용
   - 시트에 Projects / Surveys / Teams / Responses 탭이 생깁니다
7. **비밀번호 변경**: `setAdminPassword` 함수 안의 `'여기에_새_비밀번호'`를 바꾸고 실행 (기본값 `wenew1234`)
8. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** ← 응답자가 로그인 없이 접속하려면 필수
9. 나온 웹앱 URL(`…/exec`)이 **관리자 주소**입니다. 북마크하세요.

## 2. 사용 순서

1. **프로젝트** 탭 → 새 프로젝트 (예: 김천 부곡동)
2. 상단에서 프로젝트 선택 → **설문** 탭 → 새 설문
   - "자주 쓰는 문항" 버튼으로 성함·연락처·연령대·관심평형 등 바로 추가
   - "기본 문구 넣기"로 개인정보 동의 문구 삽입 (입력하면 동의 필수)
3. **팀·조 / 배포링크** 탭
   - 일괄 추가: `1팀,A조` 한 줄씩 입력 → 팀·조마다 링크코드 자동 발급
   - 설문 선택 → 팀·조별 링크 **복사** 또는 **QR** (현장 배너·전단용)
   - "전체 복사(엑셀용)" → 엑셀에 붙여 넣어 팀장에게 배포
4. **대시보드**: 전체/프로젝트별 응답 수, 일자별 추이, 팀별·팀·조별(오늘/누적), 설문 선택 시 문항별 분포

## 3. 데이터

| 시트 | 내용 |
|---|---|
| Responses | 전체 응답 원장 (통계의 기준) |
| RAW_설문명_xxxx | 설문별 로우데이터 — 문항이 열로 펼쳐져 바로 엑셀 다운로드 가능 |
| Projects / Surveys / Teams | 설정 데이터 (직접 수정 비권장) |

- 응답은 제출 즉시 시트에 기록됩니다 (동시 제출은 잠금 처리).
- 엑셀이 필요하면 RAW 시트를 열고 **파일 → 다운로드 → xlsx**.

## 4. 운영 팁·주의

- **코드 수정 후에는** 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포. (URL은 그대로 유지)
- 팀·조 **이름 수정**은 링크가 유지되고, **삭제** 후 재등록하면 코드가 바뀝니다.
- 응답이 있는 설문은 삭제 대신 **마감** 처리하세요. 문항 제목 수정은 RAW 열이 유지됩니다.
- 응답 화면 상단에 구글의 "Google에서 만든 앱이 아닙니다" 안내 띠가 표시됩니다 (Apps Script 무료 배포의 특성).
- 감당 규모: 하루 수천 건까지는 무리 없습니다. 응답이 수만 건 쌓이면 대시보드 로딩이 느려지니, 프로젝트 종료 후 시트를 복사·보관하고 Responses를 비우는 것을 권장합니다.
- 관리자 비밀번호는 단순 인증입니다. 링크를 아는 사람은 설문에 응답만 할 수 있고, 데이터 열람은 비밀번호와 시트 권한이 있어야 합니다.
