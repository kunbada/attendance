# 분양계약관리 앱 사용안내

## 파일
| 파일 | 용도 |
|---|---|
| `분양계약관리.html` | 앱 본체. 크롬/엣지로 더블클릭해서 실행 (인터넷 없어도 동작) |
| `초기데이터_양주역중흥S클래스.json` | 기존 엑셀에서 변환한 데이터 (세대 526 · 계약 558 · 가계약 83 · 동호지정 106 · 잠금 72 · 입금 2,464) |
| `gas/Code.gs` | 구글시트 온라인 DB용 Apps Script 코드 |
| `tools/convert.py` | 엑셀 → JSON 변환기 (엑셀로 계속 작업하다 넘어올 때 재변환용) |

## 처음 시작 (5분)
1. `분양계약관리.html` 실행 → **설정·백업** → **초기데이터(JSON) 불러오기** → `초기데이터_…json` 선택
2. **백업 폴더 지정** → 이 폴더 안에 `backup` 같은 폴더를 만들어 지정 (변경 시 1분 내 자동 저장, 시간별 스냅샷 보관)
3. (온라인 DB) 새 구글시트 → 확장 프로그램 → Apps Script → `gas/Code.gs` 붙여넣기 (Claude Code에서는 clasp로 자동) → `TOKEN` 변경 → 웹 앱 배포(실행: 나 / 액세스: 모든 사용자)
4. 앱 **설정·백업**에 웹앱 URL·토큰·사용자 이름 입력 → **저장 & 연결 테스트** → **이 PC 데이터를 서버에 전체 업로드**
5. 다른 PC는 HTML 파일만 복사해서 열고 URL·토큰 입력하면 자동으로 받아옵니다

## 비상시
- **인터넷 끊김**: 그대로 계속 작업. 우측 상단에 `오프라인 · 대기 N`으로 표시되고, 연결되면 자동 전송
- **PC 고장/교체**: 새 PC에서 HTML 열고 → 설정 → **백업 파일에서 복원** → `…_최신백업.json`
- 브라우저를 다시 켜면 백업 폴더 권한을 1회 다시 허용해야 합니다 (상단 노란 배너 클릭)

## 수금 (스피드조회)
- **수금관리 → 입금내역 올리기** → 파일을 끌어다 놓거나, 화면을 드래그 복사해서 붙여넣기
- 중복(거래일시+금액+잔액)은 자동 제외, 최근순 파일은 시간순으로 자동 정렬, 이전 날짜 누락분은 제자리에 끼워넣기
- 기재내용(`103-1302고정`, `104동1002호최`, `1032402박성민` 등)과 이름으로 동호·회차 자동 추천 → 확실한 건은 자동 분류, 나머지는 ✓ 클릭 또는 일괄 적용
- **잔액불연속** 필터: 앞뒤 거래 잔액이 이어지지 않는 곳 = 누락된 거래가 있을 가능성

## 계약서 출력
- **출력** 메뉴에서 계약서 스캔 이미지를 배경으로 올리고 필드를 끌어 위치를 맞춘 뒤 시험 출력
- **보정용 눈금 인쇄**를 실제 용지에 찍어 보면 칸 위치(mm)를 바로 읽을 수 있습니다
- 인쇄 설정: 여백 없음 · 배율 100% · 머리글/바닥글 해제
